# PRD — Google 로그인

## 배경

현재 이메일/비밀번호 로그인만 지원한다. 신규 가입 이탈률이 높아 Google OAuth를 추가한다.

## 목표

신규 사용자가 Google 계정으로 3클릭 이내에 가입과 로그인을 완료할 수 있다.

## 요구사항

### R1. Google 로그인 버튼

- 로그인 페이지와 가입 페이지 양쪽에 노출한다.
- 클릭 시 Google OAuth 팝업을 띄운다.

### R2. 신규 계정 생성

- Google에서 받은 이메일로 기존 계정이 없으면 새 계정을 생성한다.
- 프로필 이름과 아바타 URL을 Google 프로필에서 채운다.
- 생성 후 `/dashboard`로 이동한다.

### R3. 기존 사용자 로그인

- 이미 Google로 가입한 사용자는 팝업 완료 후 바로 `/dashboard`로 이동한다.

### R4. 세션

- 세션 유효기간은 30일.
- 새로고침 후에도 로그인 상태가 유지된다.
- 세션 만료 시 로그인 페이지로 유도한다.

### R5. 로그아웃

- 로그아웃 시 세션을 삭제하고 `/login`으로 이동한다.

### R6. 보호된 라우트

- 비로그인 사용자가 `/dashboard`에 접근하면 `/login`으로 리다이렉트한다.

## 비목표

- 다른 OAuth provider(Apple, GitHub)는 이번 범위 밖.
- 기존 이메일/비밀번호 로그인 제거는 하지 않는다.

## 성공 지표

- 가입 완료율 기존 대비 +15%
