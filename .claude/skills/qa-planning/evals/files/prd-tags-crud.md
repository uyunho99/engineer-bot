# 스펙 — 태그 관리

내부 관리자 도구의 태그 CRUD. 인증은 이미 도구 전체에 걸려 있어서 이 화면 자체에는 권한 분기가 없다.

## 화면

`/admin/tags` 한 페이지.

## 요구사항

- 태그 목록을 이름 오름차순으로 보여준다. 페이지당 20개, 페이지네이션.
- 태그를 추가한다. 이름은 1~30자, 중복 불가.
- 태그 이름을 수정한다. 같은 검증 규칙.
- 태그를 삭제한다. 확인 모달을 띄운다.
- 목록 상단에 이름 검색 입력이 있다. 입력 시 클라이언트 필터링.

## 비목표

- 태그 색상, 계층, 병합 기능은 범위 밖.
